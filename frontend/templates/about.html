Engineering Specification

StrongHold is a production-grade, non-custodial Bitcoin escrow platform designed to enable recovery-centered lending and decentralized community savings (SACCO) coordination. Built on open-source Bitcoin infrastructure, the system enforces financial accountability through cryptographic multisignature contracts, verifiable clinical milestones, and transparent collateral management.

🔗 Bitcoin Layer (L1)

  • bitcoinjs-lib: Multisig script building & transaction crafting
  • ecpair + tiny-secp256k1: ECDSA signing & key management
  • Mempool.space API: Transaction broadcast & confirmation tracking
  • P2WSH (P2SH): 2-of-3 witness script escrow contracts

⚡ Lightning Network

  • Alby WebLN API: In-browser Lightning payments & invoice handling
  • LNbits: Self-hosted or community Lightning node gateway
  • Micro-payments: Instant survey compensation at scale

🗄️ Backend & Database

  • Node.js + Express: RESTful API server & middleware
  • Supabase (PostgreSQL): User accounts, vault state, oracle logs
  • JWT Sessions: Stateless authentication tokens

🎨 Frontend & UX

  • Vanilla JavaScript: No framework overhead, cryptographic UI state
  • Responsive CSS Grid: Mobile-first dark theme dashboard
  • localStorage: Client-side session persistence & key management

Core Mechanisms

2-of-3 Multisig Escrow (Model A: Recovery-Bound)

Signers: Sponsor (Donor), Patient (Recipient), StrongHold Server (Oracle)
Release Path: Sponsor + Patient signatures after clinical milestones verified
Breach Path: Sponsor + Server signatures to refund on protocol violation
Script Type: OP_CHECKMULTISIG (2-of-3 threshold)

Volunteer Vesting (Model B: Task-Bound with CLTV)

Mechanism: Tasks unlock Bitcoin rewards after 14-day warranty lock (CheckLockTimeVerify)
Purpose: Ensures work quality & protects platform from malicious submissions
Script Type: OP_CLTV + OP_DROP (time-lock branch conditions)

SACCO Collateral Management (65% LTV Rule)

Calculation: Max Borrow = (BTC Holdings × Price) × 0.65
Liquidation Trigger: Automatic when collateral ratio drops below 65%
Purpose: Protects pooled member savings from market volatility
